# Marktzettel

Eine schlanke Einkaufsliste als iPhone-PWA. Mehrere Listen, dauerhafte Standardartikel, Mengen, Kategorien, Teilen und Offline-Nutzung. Die Daten werden lokal im Browser auf dem jeweiligen Gerät gespeichert.

## Auf dem iPhone installieren

Die Seite in Safari öffnen, auf „Teilen“ tippen und „Zum Home-Bildschirm“ wählen. Beim ersten Öffnen muss kurz Internet vorhanden sein, damit die App-Dateien für die Offline-Nutzung geladen werden.

## Dateien

- `index.html` – Oberfläche
- `styles.css` – responsives Layout
- `app.js` – Listen, Artikel und lokale Speicherung
- `service-worker.js` – Offline-App-Shell
- `manifest.webmanifest` – PWA-Einstellungen
